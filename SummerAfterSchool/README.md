# 放学后

一款以 1990 年代中国小镇为背景的 Unity 3D 打圆卡游戏。Windows 0.5.6 让出手者可以从场地任意方向站位，并在出手前改变片角和镜头观察角度；0.5.5 的伙伴身份、招呼与结果动作继续保留。继续保留 0.5.4 可操作教学、八处街区、八关故事与八人锦标赛，以及保存退出和比赛俯视视角。玻璃珠是买卖圆片的货币；本版没有弹玻璃球游玩入口。

## 直接玩

双击桌面上的「放学后」快捷方式，或工作区中的 `开始玩.cmd`。也可直接打开 `Builds/Windows-v0.4/放学后.exe`。完整保留它旁边的 `放学后_Data` 文件夹与 Unity 运行库。本轮完整上一稳定 0.5.5 保存在 `Builds/Windows-v0.4-before-free-angle-056-stable-20261009/`。

2026-10-04 修复了启动批处理在本机的编码/换行解析问题。`开始玩.cmd` 使用纯 ASCII 与 CRLF，不再切换代码页；它调用带 UTF-8 BOM 的 Windows PowerShell 启动器，检查运行库、记录日志，并在失败时显示说明。日常启动使用游戏内记忆的显示设置，不使用验证模式。支持窗口化、全屏窗口化和全屏；更换模式有 15 秒确认倒计时，未确认会恢复。启动器和发布快捷方式不再强制指定窗口尺寸或模式。启动诊断见 `Logs/launcher.log` 和 `Logs/play.log`；桌面快捷方式直接指向真实运行文件。

首页可以进入故事、锦标赛、自由约战、铁盒、小卖部或街坊跑腿。第一次可先用练习片「玩假的」或「自己练手」；故事、锦标赛和「玩真的」都要双方各押一张真片。

Android 手机版位于 `Builds/Android-v0.5/after-school.apk`，本次交付另提供 `after-school-0.5.3.apk`。当前手机版为 `0.5.3`（`versionCode=4`）：采用独立横屏 UI，放大文字和触控区；首页六个大入口、铁盒每页六张、约战分三步，比赛操作置于左右两侧并保留中央拖拽区。继续保留 `0.5.2` 的人物模型启动修复。横屏、ARM64，支持安全区与单指拖拽。构建方法与验证范围见 [Android 说明](docs/ANDROID.md)。

自由打片可选择放学老阵、扇面开彩、两岸夹击和圈边五子；故事与杯赛使用关卡规定的阵型。阵型改变开局位置，翻面和越界得分仍来自实际碰撞与停稳。

八处地点是外婆小院、小学门口、汽水胡同、老槐树下、小区广场、小卖部门口、教学楼走廊和校园操场。战场外圈有可碰撞的路沿，粉笔圈仍是出圈得分线；井盖、花纹砖、起伏砖、台阶和排水槽有实际高低与摩擦。重访会改变摊位、摆设和路人，比赛地形与 Boss 擂台保持固定。上午、正午、下午、傍晚配合晴天、多云和小雨；天气每局固定，户外小雨轻度降低摩擦，小卖部檐下与走廊保持干燥。

## 在 Unity 中继续开发

使用 **Unity 6000.3.25f1**，在 Unity Hub 中添加本目录。

也可双击工作区中的 `打开Unity工程.cmd`，它会使用本机已经安装并激活的 Unity 打开工程。

打开 `Assets/Scenes/SummerTown.unity`，点击 Play；或者使用菜单「放学后 → 运行游戏」。街区、玩法和 UI 会由 `SummerGame` 在进入运行模式时创建。当前场景采用内置渲染管线，没有外部插件或模型推理运行依赖。

「放学后 → 导出 Windows 试玩版」可以重新构建。命令行也可执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\build.ps1
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住地面或出手片，往后拖，松开 | 方向与蓄力出手 |
| 1 / 2 / 3 | 掌拍 / 重拍 / 斜擦 |
| A / D，或按住鼠标中键左右拖动 | 绕场改变出手站位（0°–360°） |
| W / S | 调整镜头俯仰 |
| 鼠标滚轮 | 调整镜头远近 |
| Q / E | 调整出手旋转 |
| 「站位与片角」面板的前后倾 / 左右倾 | 调整圆片倾角（各 ±35°） |
| 「站位与片角」面板的复位按钮 | 恢复默认站位、倾角与旋转 |
| 蓄力时右键 | 取消这次出手 |
| 比赛中按 V | 切换俯视 / 斜俯视打片镜头 |
| Esc | 暂停 / 继续，或收起当前浮层 |
| M | 音乐与音效静音开关 |
| F3 | 查看实时物理数据 |

翻面制：目标圆片停稳且正面朝下才得分。出圈制：整张圆片越过边界才得分。双方轮流出手，先得 3 张获胜；14 手后按得分结算。

普通对局在未得分的出手后保持安静，不再显示“没碰上”“下一手换个角度”之类的失败提示；手机与电脑版一致。得分庆祝、回合状态和分步教学指引继续显示。

0.5.4 的「跟小雨学出手」有三个可重复步骤：先取消一次蓄力并重新出手，再用掌拍中等力道碰到薄荷绿纸边并翻面，最后用斜擦从圈内侧把目标片完整送出圈。教学会显示动作箭头和掌拍 25%–78% 的中等力道区；每次出手停稳后保留真实盘面，失败通过「再试一次」重摆，成功通过「继续下一步」推进。教学不改变钱包、收藏实例、时段或 pending，只保存 `guidedPracticeCompleted`。

比赛提供正上方俯视镜头，方便观察圆片、粉笔圈和出圈边界；HUD 左上角的「俯视视角」按钮与 `V` 键都可以切换。自由站位面板显示当前站位、前后倾和左右倾；A/D 与中键绕场，W/S 调斜俯视仰角，滚轮调远近，Q/E 调旋转。正上方模式保持固定俯视，W/S 调整的仰角会在切回斜俯视后显示。面板倾角会改变待出手片的真实姿态，但不改变碰撞规则或得分判定。

故事依次解锁八关：四场普通约战、三场地区 Boss 和一场操场大 Boss。普通关首次胜利奖励 4 颗珠，地区 Boss 首通 8 颗，大 Boss 首通 16 颗。锦标赛为八人单淘汰，玩家赢三轮夺冠，冠军奖励 24 颗；落败淘汰，平局留在本轮重赛。完整场地与对手表见 [v0.4 验收说明](docs/QA_V04.md)。

## 铁盒和约战

42 张圆片使用独立实例记录来源、转手历史、战绩和磨损，原 30 个图案 ID 保留。新增「街坊小英雄」「花纹游戏标」「校园冒险队」三系列各 4 张，前四张是 Boss 招牌。稀有图案不会自动获得更强的战斗加成；物理类型决定重量、摩擦和弹性手感。

铁盒可筛选持有、珍藏与丢失的圆片，查看最近六段经历。同图案的不同实物用详情下拉分别选择，标记保护、出手和找朋友追回都对应选中的那一张。

首页的「跟小雨学出手」进入三个无押片、可重复的真实练习：拖拽与取消、掌拍翻面、内侧斜擦出圈。教学按停稳后的结构化物理结果判定，失败会重摆当前步骤，不改变余额、赌注、时段或正式约战。完成状态独立保存为 `guidedPracticeCompleted`。

「玩假的」只记录战绩。「玩真的」赛前显示双方各押的一张，结算只交换约定赌注。练习片和标记「舍不得」的珍藏片不能押上真局。所有片都可交易，珍藏片必须明确确认眼前这一笔，确认不会永久解除珍藏标记。输掉的片留在具体朋友手里，下一次约战优先出现，可以夺回原来的那张。

真片买价依稀有度为 6 / 12 / 24 / 48 颗珠，卖价为 3 / 6 / 12 / 24；基础练习片单独买 2、卖 1。伙伴按固定清单同稀有度一换一，每份清单每天可完成一次。首次在故事或杯赛击败 Boss 会赢得对方押出的招牌原实例，并解锁该图案的小卖部兑换。

新档或首次旧档升级有 12 颗珠。输空或卖光也不会自动补片：接跑腿、去目的地、交付获得 6 颗珠，足够买一张普通真片再回来挑战。每场结算和每次跑腿完成推进一个时段，逛地图、接任务和交易不耗时，也可主动休息。

回到街区会保留约战，首页可继续。首页、暂停页、设置页和比赛页都能进入「保存并退出」确认；飞行中的出手会等待自然停稳后保存最近稳定回合，保存失败会留在游戏内并提供重试。schema2 存档位于 `Application.persistentDataPath/SummerAfterSchool-v2`，首次只读导入旧 `SummerAfterSchool` 目录，旧主档与备份原样保留。新 snapshot3 保存环境、访问变体和几何版本，先恢复战场再恢复片的位置；旧 0/1/2 快照保留兼容，未来版本明确拒读。奖励、押片转移、进度和时段在同一次原子结算提交，重复提交不重复给奖。验证模式使用独立存档。

## 美术与音乐

场景使用程序几何和原创材质，圆片印花与音效来自可复现的原创生成脚本。本地 Qwen Image 2.1 生成夏日插画，本地 ACE-Step 1.5 生成无歌词配乐；游戏启动时直接读取成品资源，无需启动模型服务。

新版强化国内老圆卡的纸边、印刷版式，保留纸层纤维、磨损与珍藏边，微风叶影、伙伴注视及错开的庆祝动作。八地点按街区扩展环境音，纸、铁、玻璃、木、软胶碰撞音继续分别调校；音乐与环境平滑切换，铁盒使用安静的收藏主题。首页或暂停面板的「声音设置」可以分别调整总音量、音乐、出手碰撞与街区环境，偏好自动保留。

生成脚本与来源记录见 `Tools/ASSET_PROVENANCE.md`，完整模型参数、提示词与种子保存在 `Tools/LocalAI`。
