# 战场边界与地形验证 · 0.3.0

2026-10-04，Unity 6000.3.25f1，Windows 原生 Player，固定步长 0.005 秒。

## 修改

- 圆片由薄凸网格改为八条内接基本盒的并集，最大半径仍为 0.31 米，视觉网格不变。显式保留圆柱惯性。高速旋转使用预测碰撞，其他运动使用连续动态碰撞。
- 四处战场都有匹配视觉的井盖、台阶、起伏砖和花纹砖。外圈路沿内边界为 x ±3.65、z -3.15…3.5；得分粉笔圈仍为中心 (0,0,0.55)、半径 1.85。
- 腾空越过路沿、严重静态重叠有几何恢复；不设置翻面朝向。每次恢复单独计数，正常得分仍只在停稳后判定。
- 三处基础铺砖与发射区齐平，避免整块铺地前缘挡住斜擦。井盖的摩擦低于石砖。
- 新开局高度、出手姿态、粉笔圈和粒子读取实体地形。弹珠使用平地，停止弹珠后恢复打片地形。
- 收片时关闭碰撞，缓存稳定姿态；续局不会读取隐藏刚体的默认零姿态，也不会记录收片动画位移。
