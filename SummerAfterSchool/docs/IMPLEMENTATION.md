## 0.5.6 自由站位与片角

- `PogMatch` 把出手起点从固定近侧扩展为 0°–360° 的场地边缘站位；A/D 或鼠标中键绕场，W/S 调镜头俯仰，滚轮调镜头远近，Q/E 调出手旋转；桌面/手机面板的前后倾、左右倾滑块调整真实片角，各限制在 ±35°。复位会清零站位偏角、片倾角和旋转，保留原有拖拽蓄力、三种打法和取消动作。
- `SceneWorld` 维护比赛相机的方位、俯仰和距离，站位变化会取消蓄力并更新片的预览姿态；镜头只改变观察和起手几何，不修改正式 PhysX、计分、NPC 难度或 snapshot3 字段。
- 待出手片的 Collider 在真正释放前关闭，预览不会推开目标；释放时恢复 Collider 并使用当前起点、方向和片角进入真实物理。暂停、浮层和教学仍通过原有输入门控。
- `SummerUIShotAngles` 与桌面/手机 UI 显示站位、前后倾和左右倾，控制区在学校、走廊、45°高俯角和正上方视角中保持可读；Q/E 调出手旋转，滚轮调相机远近。
- 原生证据见 `docs/QA_FREE_ANGLE_056.md` 与 `Logs/QA/FreeAngle-056-native-r11/`：385 项检查、10 次真实停稳出手、自然对局 1:3、30 张截图；候选通过后完整替换正式目录，上一稳定构建保留在 `Builds/Windows-v0.4-before-free-angle-056-stable-20261009/`。

## 0.5.5 伙伴来到场边

- `CompanionPersonality` 固定七位 NPC 身份的颜色、体态、动作、节奏与短问候；`CrowdActors` 由 ID 建模，实际对手占据首位，其他围观者的重访变化保持。所有人物无 Collider，不参与正式物理。
- `SummerGame.Crowd` 统一准备、比赛、教学和结算上下文；两套 UI 用 `SelectPlayMode` 同步模式。认输使用挂起局身份与 solo 标记，恢复失败回首页清理对手状态。无存档字段改动。
- 招呼与结果动作有进入/离开包络；点头插值到本帧基础姿态，避免逐帧累积。人物时钟使用缩放时间，暂停冻结。准备页短问候独立于安静的普通未得分出手；手机摘要内容滚动，详情按钮固定。
- 原生证据 `Logs/QA/Companions-055-native-r3/`：166 条检查、14 次实际停稳出手，自然 2:2 平局、暂停、完整盘面续局、读盘、首页认输身份、走廊小雨教学和14张截图通过。手机两个比例各125条准备页检查通过，不视为Android真机通过。

## 0.5.4 可操作教学

- `GuidedPractice` 以 `ShotObservation.targetCollisionCount` 区分真实碰到目标片和仅碰到地面；每次停稳结果保留在盘面上，失败不自动重摆，成功不自动切步。
- 教学结果通过 `guided-action` 明确继续或重试；同一步重试保留取消动作和尝试次数，新步骤才重置。第三步真实斜擦出圈后写入 `guidedPracticeCompleted`，完成按钮返回街区。

## 可操作内容

- 街区入口：外婆家的小院、小学门口、汽水胡同、老槐树下。场景使用程序化模型、暖色照明、地表纹理与环境物件搭建。
- 打圆片：五张场上目标片，翻面或完整出圈得分；先拿到三张获胜，最多十四手。双方轮流出手；自己练手模式没有 NPC 回合。
- 打片四种摆阵、玻璃球四种挑战阵型；开局位置可选，经典阵保持此前校准坐标。NPC 根据规则、阻挡、周围目标及圈边方向选点，练习反馈根据实际碰撞、移位和判分生成。
- 三种出手：掌拍、重拍、斜擦。拖拽决定方向与力度；A/D 与中键绕场，W/S 调斜俯视仰角，滚轮调镜头远近，`Q` / `E` 调出手旋转；底部面板滑块调片倾角，`1` / `2` / `3` 切换打法。正上方模式固定俯视，W/S 的仰角变化在切回斜俯视后显示。碰撞与掀边力使用刚体模拟，静止后判分。
- 两种约战：切磋只记战绩；玩真的双方各押一张，胜者仅获得事先约定的片。对方优先押上此前赢走的玩家片，提供夺回机会。
- 弹玻璃球：六次出手，把八颗玻璃球完整弹出圈；真实刚体碰撞与滚动阻力，保存最高成绩。回到街区会重开本轮。
- 铁盒收藏：三十张原创圆片，五种物理原型，卡面故事、自然语言手感、稀有度、来源、胜负、磨损和“舍不得”标记。
- 收藏筛选与珍稀排序、最近六段经历、磨损条。同图案各实物可分别选取；珍藏、拿去出手与追回按钮绑定具体实例，追回选择可优先成为相应 NPC 赌注。
- 场边伙伴：四位微缩儿童，呼吸、观察出手、拍手与得分跳跃；出手手掌、扬尘、纸屑和短慢镜头反馈。
- `Esc` 暂停，右键取消蓄力，`M` 静音，`F3` 显示物理调试信息。
- 圆片纸层与磨损、珍藏边；叶簇风动与同步影子、深度遮挡文字、微小街区生物、伙伴注视/眨眼/错开庆祝，以及只处理 3D 的轻微色调。
- 四路持久化音量、声音试听、平滑音乐与环境切换、材质细碰/出手变体/蓄力/收片/连手音。Esc 支持逐层关闭声音设置与暂停，失焦取消拖拽；暂停不会把动态物体挪回发射点。

## 收藏与恢复

初始拥有一张永久基础练习片和五张可交易片。基础片、珍藏片不可下注；玩家输光可交易收藏仍能练习。NPC 输空铁盒后也能借片切磋，借片不会变成可交易收藏。

每张片有独立实例 ID 和全部转手历史。输片保留在该 NPC 名下，夺回的是同一个实例。对局开始立即保存 pending 与约定赌注；结算保留收据，重复结算不会再次转手或增加战绩。

稳定回合会保存位置、朝向、得分、回合、已得目标、出手次数、独自练手模式和 NPC 随机序列。暂停后回街区、关闭游戏都保留待继续的约战；认输正常结算。飞行途中退出恢复最近的稳定回合，不保存飞行中的速度状态。

存档使用带 SHA-256 校验的 JSON、同目录临时文件、原子替换和备份；主档损坏可从备份恢复，双档损坏时保留原文件并报错。多实例写入冲突会拒绝覆盖较新的存档。日期、时段、经验、声望与伙伴关系已有数据接口；昼夜任务与成长系统尚未完整接入。
