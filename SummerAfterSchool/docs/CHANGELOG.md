# 版本记录

## 0.3.0 · 2026-10-04

修复薄圆片高速碰撞漏检、穿入无碰撞装饰及腾空飞出战场的问题。战场有可见实体路沿，圆片采用基本盒组合与连续碰撞，快速翻转时覆盖角运动；异常重叠和高空越界有保留朝向的几何恢复。

四处战场加入实体井盖、花纹砖、起伏斜砖和三级台阶，出生和辅助线贴合实际地形。基础铺地与发射区齐平，斜擦可通过；井盖与石砖摩擦不同。收片即退出碰撞，稳定姿态缓存修复隐藏刚体导致的续局位置丢失。

四地点压力验证、八种阵型及旧快照恢复、完整对局与 68 项数据约束全部通过。详情见 `QA_ARENA.md`。新版在 `Builds/Windows-v0.3`，既有入口与快捷方式同步更新。

## 启动修复 · 2026-10-04

修复 Windows 上 UTF-8 中文批处理、LF 换行与 `chcp 65001` 组合导致命令截断的问题。原入口改为纯 ASCII、CRLF，并调用带 BOM 的 PowerShell 启动检查器。新增桌面与工作区「放学后」快捷方式，窗口以 1280×720 打开。游戏内容和收藏存档不变；实际双击脚本同等调用返回 0，快捷方式启动后确认游戏窗口响应正常。复现证据见 `Logs/LauncherProbe/echo-probe-results.json`。

## 0.2.0 · 2026-10-03

### 玩法

打片与玻璃球各增加四种阵型。经典坐标与核心力度沿用原生校准结果；不同阵型改变选点和连碰线路。对手根据当前规则、遮挡、邻片和圈边方向判断出手。练习反馈使用实际碰撞、移动和判分，而不是固定提示。

取消蓄力、失焦、暂停不再搬动正在飞行的物体。打片快照保存阵型和练习反馈，兼容旧版本；无法识别的未来版本拒绝读取。

### 美术

圆片增加纸层纤维、边缘磨损、细划痕和珍藏边。街区增加微风叶影、微小蝴蝶与落叶；伙伴注视目标、眨眼，庆祝动作错开出现。文字遵守场景遮挡，墙绘与宣传栏避开遮挡，比赛时收起地面标题。轻微色调只处理场景，操作提示和品牌增加局部暗底。

### 声音

新增 64 个原创程序音频资源，包含四地点音景、五材质碰撞、出手变体、蓄力、收片与连手提示。短音效使用变体与微小音高变化，同帧合并、声部限制及平滑音量避免连续碰撞拥挤。音乐与环境淡入淡出，铁盒采用本地 ACE-Step 生成的 46.4 秒收藏配乐，保留原主曲。

### 界面与收藏

玻璃球选阵可预览真实摆放图。铁盒可筛选持有、珍藏及丢失圆片，排序并查看最近六段经历。相同图案的不同实物单独选择，保护与出手绑定同一实例；追回按钮指定想赢回的那一张。声音面板分别调整总音量、音乐、出手碰撞、街区环境，自动记住偏好。Esc 可逐层收起浮层、返回暂停或继续比赛。

### 交付与验证

可玩 Windows 文件继续由工作区 `开始玩.cmd` 启动。上一版完整构建保留于 `Builds/Previous-v0.1`。本轮原生验证证据、截图及适用范围见 `docs/IMPLEMENTATION.md` 和 `docs/QA_POLISH.md`；音频来源与波形报告见 `Tools/ASSET_PROVENANCE.md`。
