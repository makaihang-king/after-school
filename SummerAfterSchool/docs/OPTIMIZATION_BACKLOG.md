# 持续打磨清单

目标是把《放学后》做成细腻、耐玩、反馈舒服的童年游戏合集。每轮以一个完整体验为单位，完成实现、原生试玩验证和可玩构建后再汇报。以实际改进衡量进度，避免只增加开关和装饰。

## 已完成：0.5.6 自由站位与片角（2026-10-09）

- 出手前可以从场地任意方向站位：A/D 或中键绕场，W/S 调镜头俯仰，滚轮调远近，Q/E 调出手旋转；“站位与片角”面板用前后倾、左右倾滑块调整圆片真实姿态，复位按钮恢复默认。站位和倾角状态在面板中实时可读。
- 预览片在真正释放前没有 Collider，避免换位时推开目标；释放后重新启用并由实际 PhysX 决定碰撞、停稳与得分。暂停、教学、遮挡和旧 snapshot3 兼容保持。
- 学校与走廊 24 个遮挡机位、四个绕场方位、45°高俯角、正上方、10 次真实停稳出手（自然 1:3 结算）、暂停恢复和存档回读均通过；候选构建晋级正式目录，完整上一稳定版保留。证据见 `docs/QA_FREE_ANGLE_056.md`。
- 可见窗口人工会话正常退出且偏好/真实存档不变；桌面自动化通道未返回候选窗口，因此按键拖拽的人工观察没有冒充通过，后续可在用户可控窗口中补做体验复核。

- 小雨挥手、大志抬拳、桃桃画弧、林林克制点头，准备页短招呼与得分/结算回应形成完整体验。普通未得分出手仍保持安静。

## 下一轮优先级

1. **伙伴与街区生活**：身份、体态和手势已稳定。下一步围绕一次重访中的短事件，让现有伙伴与地点、天气或圆片经历发生具体联系；每次只做一个完整事件，不扩充空角色或无意义开关。
2. **画面层次**：检查四地点近景材质、接触阴影、纸片可读性和玻璃球内芯。控制光效，确保选中对象、边界和落点在各种背景都清楚。
3. **音乐与音效**：听完整循环和连碰场景，修突兀重复、遮盖、过响提示。为比赛准备有起伏但不干扰判断的本地生成配乐。
4. **耐玩性**：有明确规则与奖励的小挑战、朋友的日常约战与圆片故事，避免重复刷局和无意义数值堆叠。
5. **合集扩展**：现有玩法达到稳定体验后，再增加纸飞机、沙包等完整玩法，复用街区、伙伴、铁盒和音景。

## 每轮发布约定

- 先读当前版本、最近改动和此清单，选择最有价值的一组问题。
- Unity 编辑器或游戏正在由用户使用时，保留用户会话，等待空闲再覆盖构建。
- 本地重模型一次只跑一个，生成完成后释放自启进程；记录来源、参数和种子。
- 使用隔离存档验证实际物理、结果、恢复、UI和画面。只在新改动、失败或疑点需要时扩大回归范围。
- 新版通过验证前保留上一版可玩构建；失败时修复或保留稳定版，明确记录未完成项。
- Windows `.cmd` 保持纯 ASCII、CRLF，不加入 `chcp` 与中文文本；包含中文的 Windows PowerShell 5.1 脚本使用 UTF-8 BOM。发布时检查真实双击入口和快捷方式，不能只通过隐藏验证窗口判断日常启动正常。
- 只在有可玩的实质改进、失败或需要用户操作时通知；状态不变时保持安静。

用户反馈优先于此清单。自动验证能发现流程和物理错误，审美、节奏与“玩起来爽”的判断仍需要反复真实试玩。
