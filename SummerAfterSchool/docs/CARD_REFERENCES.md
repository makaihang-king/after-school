# 纸圆片与旧卡片的实物参考

调研日期：2026-10-04。用途：指导《放学后》的原创圆片画面、纸材质和收藏系统，不建立未经查证的厂商名录，不复刻现成动漫角色、商标或扫描图。

## 结论与证据边界

目前没有可靠材料足以确认中国大陆九十年代常见纸圆片的具体印刷厂商、完整品牌系列或统一的玻璃珠兑换比例。市场卖家写的“小二郎”“小当家”等名称只能作为待核线索，不能直接写入游戏为“老牌圆片厂家”。动漫作品名是图案题材，食品品牌是发行或促销方，两者都不自动等于纸圆片制造者。

可确认的海外纸圆片生产者是 Stanpac；Canada Games 有博物馆实物与档案支持；World POG Federation / POG Unlimited 可确认品牌权利和授权角色。台湾历史博物馆的纸质尪仔标实物能支持圆片外形和印刷布局，但其制造者与制造地多登记为“不详”。

## 本作采用的原创设计推导

以下是本作的设计选择，不是对历史厂商产品的复制或对历史兑换制度的断言：

- 每片以原创街区人物、童年小物或原创机甲作为清晰中心画面，外圈保留大色带与少量编号；辅助符号用于整理套系，避免细字挤满小圆面。
- 背面使用统一的原创几何暗纹或街区徽记，正反面明暗关系明确，便于观察是否翻面。普通片用少量套色和纸质感；更稀少的片可采用局部亮面或金属色印刷的原创视觉表现。
- 纸边应有可读的薄厚和纤维色差，磨损来自实际使用状态；新片、磨旧片、褪色片具有不同收藏感，不把所有片都处理成同样的黄色旧纸。
- 商店购买、同伴交换、赢取对手押片、成套收集均使用单张实例和来源记录。玻璃珠是本作的兑换货币，价格与交换比例由游戏平衡确定，不能声称为全国历史通行规则。
- 参考图像只用于研究尺寸、版式、套色、纸边与背纹。不把现有动漫名称、人物剪影、商标或博物馆图片嵌入可发行资产；角色与系列命名由原创世界观产生。

## 后续查证方式

若收到国内旧圆片实物，优先记录整袋包装正反面、厂名与地址、商标、系列编号、条码、圆片背面印记及可确认购入地点；再用当地工商/地方志/报刊或收藏机构记录交叉核实。仅凭商品标题和相同角色画面不能建立厂家归属。
